# Triage Labels

| 角色 | 标签 | 说明 |
|------|------|------|
| 需要评估 | `needs-triage` | 维护者需要评估 |
| 等待补充 | `needs-info` | 等待报告者补充信息 |
| Agent 可认领 | `ready-for-agent` | 规格完整，agent 可直接认领 |
| 需要人工 | `ready-for-human` | 需要人工实现 |
| 不修 | `wontfix` | 不予处理 |
